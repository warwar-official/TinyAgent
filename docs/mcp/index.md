# MCP System Documentation

TinyAgent uses a Model Context Protocol (MCP) inspired architecture to manage external tools, prompts, and system state.

## Available MCPs

| MCP Name | Description | Link |
| :--- | :--- | :--- |
| **Prompt Builder** | Manages system and role-specific prompts. | [prompt_builder.md](prompt_builder.md) |
| **Base Tools** | Core capabilities like web search, weather, and YouTube transcripts. | [base_tools.md](base_tools.md) |
| **Identity** | Manages the agent's persona, language, and behavioral constraints. | [identity.md](identity.md) |
| **Memory** | Handles long-term RAG memory, skills database, and archived conversations. | [memory.md](memory.md) |
| **Spotify** | Full control over music playback, playlists, and lyrics. | [spotify.md](spotify.md) |
